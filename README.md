# StudySphere — One Browser. Every Student Need.

StudySphere is an intelligent, all-in-one student workspace and educational productivity platform combining an AI study copilot, timetable planner, group study rooms, and coding tracker.

## 📱 Software Application & App Store Distribution

StudySphere is fully packaged and ready to be downloaded and distributed on:
- **Google Play Store (Android)**: Native Android project powered by Capacitor (`com.studysphere.app`) with adaptive icons, splash screens, and offline support.
- **Microsoft Store (Windows)**: Store-compliant PWA packaged as MSIX with Start Menu live tiles, taskbar pinning, and isolated desktop window.
- **Direct 1-Click PWA Installation**: Instant installation directly from Edge/Chrome on Windows, macOS, Android, and iOS.

See the complete step-by-step publishing instructions in:
👉 **[`docs/STORE_PUBLISHING_GUIDE.md`](./docs/STORE_PUBLISHING_GUIDE.md)**

## 🚀 Quick Scripts

```powershell
# Run local development server
npm run dev

# Build web application bundle
npm run build

# Build and sync to native Android project
npm run build:android

# Open native Android project in Android Studio
npm run open:android

# Regenerate all PWA, Android, and Microsoft Store icons
npm run generate:icons
```
